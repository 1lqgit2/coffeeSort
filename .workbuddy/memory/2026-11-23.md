# 2026-11-23

## 修复 Google.IOSResolver.dll 引用解析报错

- 现象：`Assembly 'Assets/ExternalDependencyManager/Editor/1.2.179/Google.IOSResolver.dll' will not be loaded due to errors: Unable to resolve reference 'UnityEditor.iOS.Extensions.Xcode'`
- 根因：Unity 安装 `C:\Unity\engine\2022.3.62f3c1` 只装了 WebGL + Windows Standalone 两个 PlaybackEngine，没有 iOS Build Support，故 `UnityEditor.iOS.Extensions.Xcode.dll` 不存在。EDM4U 1.2.179（2016 年版本，以 dll 形式内嵌在 Assets）的 iOS Resolver 编译时引用了它。
- 处理：把 `Assets/ExternalDependencyManager/Editor/1.2.179/Google.IOSResolver.dll.meta` 的 `validateReferences: 1` 改为 `0`（插件 Inspector 里的 "Validate References" 取消勾选）。原文件备份在项目根 `Backup_EDM4U_iOSResolver_fix/`。
- 影响面：仅编辑器程序集加载警告，不影响 Android/WebGL 构建与运行；iOS Resolver 在非 iOS 平台不会被真正调用。
- 备选方案：①删掉 iOSResolver 的 dll/pdb（4 个文件）；②Unity Hub 安装 iOS Build Support 模块；③整体升级 EDM4U 到 1.2.18x（1.2.179 太旧，对 Unity 2022 兼容性差）。
- 环境事实：该项目 Unity 版本无 Android Build Support 模块，若要打 Android/抖音 APK 需先安装该模块。
