## 修复 Unity Ads「Invalid configuration request for gameId:」报错

- 报错堆栈：`UnityEngine.Advertisements.Utilities.CoroutineExecutor:Update()`（com.unity.ads 4.12.0）
- 根因：`Assets/Scripts/Managers/AdsControl.cs` 的 `Start()` 无条件调用 `InitializeUnityAds()`；而 `Assets/Scenes/Game.unity` 里 AdsControl 的 `androidUnityGameId` / `iOSUnityGameId` / 所有 Unity Ads 广告位字段全为空，`currentAdsType: 0`(ADMOB)。`Advertisement.Initialize("", false, this)` 触发原生层 gameId 非法。
- 另有两个隐藏 bug：
  1. `InitializeUnityAds()` 的宏分支只有 `UNITY_IOS / UNITY_ANDROID / UNITY_EDITOR`，WebGL 构建下三者都不成立 → `unityGameId` 为 null；
  2. `Start()` 里 `adUnityRWUnitId` 同样只在 iOS/Android 下赋值，WebGL/Editor 下保持 null。
- 修改（备份 `Backup_AdsControl_UnityAdsFix/AdsControl.cs.bak`）：
  1. `Start()` 按 `currentAdsType` 决定初始化哪个 SDK（ADMOB / UNITY / MEDIATION），不再无条件初始化两套；
  2. `adUnityRWUnitId` 与 `unityGameId` 改为 `#if UNITY_IOS / #else` 兜底取 Android 值；
  3. `InitializeUnityAds()` 增加 gameId 空值保护，空则 LogWarning 并 return，不再调用 `Advertisement.Initialize`；
  4. `PlayUnityVideoAd()` 增加 adUnitId / isInitialized 保护，不可用时回调 SKIPPED，避免 `Show(null)` 与 UI 卡流程。
- 注意：改动需切回 Unity 触发重编译（编辑器 PID 持锁，无法 batchmode 验证）。
- 待办隐患：项目实际广告方案是抖音（`Assets/AdSDK/Scripts/AdManager.cs` + TTSDK），但 UI（UIBuyItem/UIHeartInfo/UIRevive）仍走 `AdsControl.currentAdsType=ADMOB` 的 Google 测试 ID，WebGL 抖音包上不可用，需要后续统一切到 AdManager。

## 16:33 修 WebGL 平台编译错误：`Handheld` 不存在（CS0103）
- 报错：`SoundManager.cs(149,13): error CS0103: The name 'Handheld' does not exist in the current context` + `Error building Player because scripts had compiler errors`。
- 机理：`Handheld` 属移动平台 API，**Unity 打包 WebGL 时会把它从 API profile 里剔除**，而编辑器下（Standalone）能编过，所以一直没暴露。这是打包期的**平台编译**错误，与脚本本身语法无关。
- 修法：把 `SetShock` 里的直调抽成 `SoundManager.Vibrate()`：
  - `#if UNITY_WEBGL` → `TTSDK.TT.VibrateShort(new TTSDK.VibrateShortParam())`（抖音原生短震动）
  - `#elif UNITY_ANDROID || UNITY_IOS` → `Handheld.Vibrate()`
  - **WebGL 分支写在最前**：否则编辑器把 BuildTarget 切到 WebGL 时 `UNITY_EDITOR` 仍成立，会落回 Handheld 再报错。
- TTSDK 接口位置：`ttsdk.xml` 的 `M:TTSDK.TT.VibrateShort(TTSDK.VibrateShortParam)`；`Assembly-CSharp.csproj` 已 `<Reference Include="ttsdk">` 直接引用 ttsdk.dll，不需要额外 using。
- 校验：编辑器宏 `dotnet build` 0 错误；另生成临时 `_webgl_check.csproj`（删 UNITY_EDITOR/STANDALONE 系列宏、追加 `UNITY_WEBGL;PLATFORM_WEBGL`，`-t:Rebuild`）同样 0 错误——该次编译**确实进入了 TTSDK 分支**，所以类型签名是验证过的。临时文件已删。
- 同批复查：`UnityEngine.iOS`（DeviceCapabilities/HapticController/LofeltHaptics）有 `#if (UNITY_IOS && !UNITY_EDITOR)`、`AndroidJavaObject`（JNIHelpers）有 `#if (UNITY_ANDROID && !UNITY_EDITOR)`，WebGL 均不参与编译，安全。
- `warning CS0414 nextPlateIndex 未使用` 只是警告，不阻断，未改。
- 备份 `Backup_WEBGL_SCRIPT_FIX_20261124/SoundManager.cs`。
